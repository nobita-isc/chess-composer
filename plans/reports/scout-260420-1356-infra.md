# Scout: Root-Level Infrastructure
**Date:** 2026-04-20 | **Scope:** Build, test, data, deploy configs

## 1. Scripts Directory (6 scripts)
- `build-sqlite-db-optimized.js` — Converts CSV→SQLite with themes as TEXT field (smaller DB for browser)
- `build-sqlite-db.js` — Standard CSV→SQLite converter with junction tables
- `download-puzzles.js` — Downloads & filters Lichess puzzle database from remote URL
- `filter-lichess-puzzles.js` — CLI tool to filter full Lichess CSV by theme & rating quality
- `theme-mapper.js` — Centralized theme categorization config (categories, icons, displayNames)
- `setup-full-database.sh` — Orchestration script: downloads (500MB), decompresses (2GB), filters Lichess DB

**Invoked via:** `npm run build:db` | `npm run build:db:test` (--limit 1000)
